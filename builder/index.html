Scenario Builder

A standalone authoring tool for building and publishing staged, branching scenarios — schema-validated, version-controlled, reusable across every facilitator once approved.

Not yet built

What's coming here

This is Phase 4 of the platform plan. It will let an author:

  • Define a baseline, staged deterioration/branching model, and named endpoints without hand-writing JSON
  • Set trigger conditions, transition/hold durations, success criteria, and reveal rules per stage
  • Import/export scenario JSON with schema validation and clear, line-level error reporting
  • Publish an approved scenario so it's available to every facilitator, not just this machine
Access model: authoring is a separate role from running a session. A facilitator can drive and adjust any published scenario live with no login. Building or saving a new scenario here will require a passcode once Supabase Auth is wired in (Phase 3 foundation → enforced here in Phase 4) — this page doesn't gate anything yet because that auth layer doesn't exist yet either.
