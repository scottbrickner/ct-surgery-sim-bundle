Before you start

Both devices are plain web pages — nothing to install. Open them in a browser and they work; open more than one at once and they sync automatically.

  • Running locally for practice? Start the server once with node serve.js, then open http://localhost:8080/.
  • Running a real session? Just open ct-surgery-sim.netlify.app — nothing to start.
  • Any window/tab of IntelliVue or HemoSphere opened on the same computer automatically shows the same patient, live, with zero setup — that's the fastest way to demo both monitors side by side.
This guide's scope

This covers running IntelliVue and HemoSphere Alta directly, on their own — each device has its own facilitator controls built in, so you don't need anything else to get started. A later guide will cover the Facilitator Console (which unifies control of every device from one screen), building custom scenarios, and the Pacemaker / ZOLL / Patient Assessments Monitor.

IntelliVue basics

Simulates a Philips IntelliVue MX-series bedside monitor — ECG, pleth, arterial line, PA line, CVP, respiration, and capnography waveforms, plus the numeric tiles a real unit shows.

Opening the controls

  1. Open the IntelliVue page.
  2. Click Facilitator in the bottom-right corner of the screen (or press F). A panel titled Facilitator Control slides in from the right.
  3. Click the × in the panel's top-right corner, or press F again, to close it — the monitor screen underneath is exactly what a learner sees, so close the panel before stepping back to observe.

Loading a scenario

The fastest way to set up a teaching moment is Load Scenario, at the top of the Facilitator Control panel — five one-click presets:

  • CTICU Baseline — stable post-op cardiac patient, no alarms.
  • Symptomatic Bradycardia — sinus bradycardia with hypotension.
  • Respiratory Desaturation — a sedation-hold / post-extubation picture.
  • Septic Shock (PA cath) — elevated CO, low SVR, PAP line shown.
  • Neuro / ↑ ICP — ICP/CPP tiles shown, Cushing's pattern.

Click any one of them and the monitor updates immediately — numerics, waveforms, and which tiles are on screen all change together.

Setting the rhythm

The Rhythm dropdown (below the CT Surgery scenario section) drives the actual ECG waveform shape, not just the number — selecting a rhythm redraws real, distinct morphology for that rhythm, not a generic trace with a different label. The library covers the full range a class typically needs: sinus rhythm/brady/tach, atrial fibrillation, atrial flutter, SVT, junctional, all three degrees of AV block (including both types of 2°), paced, VT, torsades, VF, and asystole.

Adjusting vitals live

Scroll to Vital Signs for direct sliders — HR, SpO₂, ART sys/dia, CVP, PAP sys/dia, PAWP, ICP, RR, etCO₂, CO/CI, and temperature. Drag any slider and the monitor updates in real time, waveform included. Parameters On Screen, just below, is where you choose which extra tiles are visible — ECG, pleth, RR, and NBP are always on; toggle ART, a second arterial line, PAP, CVP, ICP, CPP, etCO₂, CO/CI, and temperature on or off to match what this patient actually has lines for.

Also available, not covered here

The panel also has tools for teaching specific skills — arterial-line waveform troubleshooting (site, damping, valve pathology, a fast-flush test), a PA catheter with RV migration/wedge procedure, dynamic events (hemorrhage, a Levophed drip, fluid boluses, a PVC, VF arrest), and a Progressive Transition tool that ramps the whole picture toward a target over a set time. Worth exploring on your own — a deeper walkthrough of these is planned for a future version of this guide.

Syncing to a learner's screen

The Cross-Device Sync section shows whether this window is currently linked to another one. For a learner on a separate device (a tablet, a second laptop), click Open Learner Display to get a clean link with no facilitator chrome, or use Copy Learner Link to send it another way. For a device that isn't on the same network as this computer, enter a Relay URL first and click Connect Relay — same-machine sync needs none of this.

Keyboard shortcuts

With the monitor window focused: F toggles the facilitator panel, Space silences the current alarm. The panel itself lists the rest (full-screen, zero, flush, inject a PVC) in its own footer note.

HemoSphere Alta basics

Simulates an Edwards Acumen HemoSphere hemodynamic monitor — cardiac output/index, SVV/PPV, SVR/SVRI, MAP, CVP, ScvO₂, and the Hypotension Prediction Index (HPI), plus its own Goal-Directed Therapy screen.

Opening the controls

Same pattern as IntelliVue: click Facilitator (bottom-right) or press F to open Facilitator Control; the same button/key closes it.

Sensor / mode

At the top of the panel, Sensor / Mode picks which physical sensor this patient is wearing — FloTrac (arterial-only), Swan-Ganz (pulmonary artery catheter + oximetry — the default, and the one that unlocks HPI and the fuller parameter set), or ClearSight (non-invasive cuff). This matters for teaching: HPI and the advanced hemodynamics need Swan CCO + Acumen IQ; ScvO₂ needs the oximetry sensor calibrated (there's a guided calibration flow under Open SvO₂ Calibration… if you want to demonstrate that workflow specifically).

Loading a scenario

Load Scenario has four one-click presets, each tuned to show a specific hemodynamic picture:

  • Stable Post-op — normal CO/CI, everything in target range.
  • Hypovolemia — SVV/PPV rise, CO/CI fall, HPI climbs.
  • Vasoplegia / Sepsis — CO rises, SVR and MAP fall, ScvO₂ drops.
  • Cardiogenic / LV failure — CO/CI fall, SVR rises, ScvO₂ falls, HPI runs high.

Adjusting vitals live

Drivers holds the sliders that move the numbers directly — CO, MAP, HR, CVP, SVV, PPV, ScvO₂, HPI, ART sys/dia, and temperature. Everything downstream (CI, SVR/SVRI, SVI, sCO/sCI) is computed live from these, exactly like the real device — you're setting the inputs a bedside clinician can't directly control either.

The Goal-Directed Therapy panel on the main screen (not the facilitator drawer) is worth knowing about even though it's learner-facing: pick a parameter and a target range, hit Start / Reset, and the monitor tracks time-in-target live — a good way to have a learner titrate toward a specific hemodynamic goal and see how they did.

Choosing what's on screen

Key Parameter Tiles is a tap-to-toggle list (sCO, sCI, SVI, SVV, PPV, SVR, SVRI, MAP, CVP, ScvO₂, HPI) controlling which tiles the learner sees on the main screen — same idea as IntelliVue's Parameters On Screen. Tap any tile on the actual monitor screen (or the "globe" trend view) to set its target range and alarm limits directly.

Same Cross-Device Sync section as IntelliVue, working the same way — Open Learner Display, Copy Learner Link, or a Relay URL for a separate device.

Running both together

Open IntelliVue and HemoSphere Alta as two windows/tabs on the same computer and they sync to each other automatically — no setup, no relay, no code. Drive vitals from either one's own Facilitator Control panel and the other updates live. Each panel's own Shared Flagship Scenario and CT Surgery scenarios (stepped) sections step through the same built-in cases identically from either device, so you don't have to pick a "master" screen.

Running a real class?

The Facilitator Console (linked from the homepage) unifies IntelliVue's and HemoSphere's controls — plus the pacemaker and Patient Assessments Monitor — into one screen on your own laptop, so you're not clicking between two facilitator panels mid-session. It's the recommended way to run anything beyond a quick solo demo. A full walkthrough of the Console is planned for the next version of this guide.

Quick troubleshooting

  • Two windows aren't syncing. Confirm they're both open on the same computer (same-machine sync needs nothing else) — a separate device needs either the Console's session link or a Relay URL entered on both ends.
  • The facilitator panel won't open. Click directly on the Facilitator label bottom-right, or click anywhere in the monitor window first so it has keyboard focus, then press F.
  • A scenario preset didn't seem to change anything. Check you clicked the preset card itself (the title + description are one button) — a partial click on the panel background does nothing.
  • Numbers look "stuck" mid-demo. Check whether a Progressive Transition is running (its status line says so, near the bottom of the panel) — while one runs, values are actively ramping toward a target and won't respond to a slider until you stop it or it finishes.
