Training simulation only. Not for clinical use. Checking for an active session…
Setup order matters
  1. Open the Facilitator Console first — it's the source of truth for whichever scenario is running.
  2. Open IntelliVue, HemoSphere Alta, and the Patient Assessments Monitor next — each syncs to the console automatically on this machine (zero setup), or via the console's session link for a separate device.
  3. Open the Pacemaker last, if this session uses it — it only overlays its live capture state onto a session that already exists, so it needs a monitor or the console open first.
