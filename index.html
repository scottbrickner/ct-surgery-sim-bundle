CT Surgery Sim Bundle

Bundled, cross-syncing training simulation for a CT (cardiothoracic) surgery nursing class — Philips IntelliVue, Edwards HemoSphere Alta, and a Medtronic 5392 temporary pacemaker, driven by one shared physiology engine.
Training simulation only. Not for clinical use.

Setup order matters

  1. Open the Facilitator Console first — that's the source of truth for the flagship case.
  2. Open IntelliVue and HemoSphere Alta next — they sync to the console automatically on this machine (zero setup), or via the console's relay link for a separate device.
  3. Open the Pacemaker last, if this session uses it — it only overlays its live capture state onto a session that already exists, so it needs a monitor or the console open first.
